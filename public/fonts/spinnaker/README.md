# Spinnaker

`Spinnaker-Regular.ttf` is the original Spinnaker Regular face distributed by
the [Google Fonts project](https://github.com/google/fonts/tree/main/ofl/spinnaker).
It restores the typeface referenced by the application's surviving legacy CSS
without requiring a third-party request from the browser.

The font is copyright 2011 Sorkin Type Co and distributed under the SIL Open
Font License 1.1 included in `OFL.txt`.
